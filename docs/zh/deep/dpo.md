# DPO：直接偏好优化（2023）

## 面试摘要

**DPO** 通过为RLHF目标推导出**闭式最优策略**来消除奖励模型。关键洞察：$r(x,y) = \beta \log \frac{\pi^*(y|x)}{\pi_{ref}(y|x)} + \beta \log Z(x)$ — 奖励可以表示为策略比率！使用Bradley-Terry偏好模型，DPO直接优化 $\mathcal{L} = -\log \sigma(\beta(r_w - r_l))$，其中 $r = \log \frac{\pi_\theta}{\pi_{ref}}$ 是**隐式奖励**。更简单的流程（无RL循环），但需要成对偏好数据并需要在内存中保留参考模型。

**需要记住的**：隐式奖励 $r = \log \frac{\pi_\theta}{\pi_{ref}}$，DPO损失公式，为什么它在数学上等价于RLHF。

---

## 关键洞察

DPO（Rafailov等，2023）提问：*我们能完全跳过奖励模型吗？*

答案是可以——通过利用RLHF目标的数学结构。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                     RLHF vs DPO 流程                                        │
└─────────────────────────────────────────────────────────────────────────────┘

传统 RLHF (PPO)：
┌──────────┐   ┌──────────────┐   ┌─────────────┐   ┌──────────────┐
│ 收集     │ → │ 训练奖励     │ → │ RL 训练     │ → │ 对齐后的     │
│ 偏好     │   │ 模型 r_φ     │   │ (PPO循环)   │   │ 模型         │
└──────────┘   └──────────────┘   └─────────────┘   └──────────────┘
     ↓              ↓                   ↓                 ↓
  (y_w, y_l)    独立的NN          Actor + Critic      π_θ

DPO：
┌──────────┐   ┌─────────────────────────────────┐   ┌──────────────┐
│ 收集     │ → │ 直接在偏好上优化                │ → │ 对齐后的     │
│ 偏好     │   │ (单一监督损失)                  │   │ 模型         │
└──────────┘   └─────────────────────────────────┘   └──────────────┘
     ↓                        ↓                           ↓
  (y_w, y_l)        不需要奖励模型！                    π_θ
```

**为什么重要**：DPO消除了整个RL训练循环和奖励模型训练，使对齐变得更简单、更稳定。

## 数学推导

### 步骤1：RLHF目标

回顾标准RLHF目标：

$$\max_\pi \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi} \left[ r(x, y) \right] - \beta D_{KL}(\pi \| \pi_{ref})$$

展开KL散度：

$$= \mathbb{E}_{x, y \sim \pi} \left[ r(x, y) - \beta \log \frac{\pi(y|x)}{\pi_{ref}(y|x)} \right]$$

### 步骤2：最优解

这是一个约束优化问题。取导数并令其为零，最优策略有闭式解：

$$\pi^*(y|x) = \frac{1}{Z(x)} \pi_{ref}(y|x) \exp\left(\frac{1}{\beta} r(x, y)\right)$$

其中 $Z(x) = \sum_y \pi_{ref}(y|x) \exp\left(\frac{1}{\beta} r(x, y)\right)$ 是**配分函数**（归一化常数）。

**直觉**：最优策略是按指数化奖励重新加权的参考策略。高奖励 → 更高概率。

### 步骤3：重新整理得到奖励

这是关键技巧——我们解出 $r(x, y)$：

$$r(x, y) = \beta \log \frac{\pi^*(y|x)}{\pi_{ref}(y|x)} + \beta \log Z(x)$$

**关键洞察**：奖励可以完全用策略比率来表示！我们不需要学习单独的奖励函数。

### 步骤4：Bradley-Terry模型

人类偏好遵循Bradley-Terry模型：

$$P(y_w \succ y_l | x) = \sigma(r(x, y_w) - r(x, y_l))$$

其中：
- $\sigma$ 是sigmoid函数：$\sigma(z) = \frac{1}{1 + e^{-z}}$
- $y_w \succ y_l$ 意味着"$y_w$ 优于 $y_l$"

**为什么是sigmoid？** Bradley-Terry模型说，偏好一个选项而非另一个的概率取决于它们"强度"（奖励）差异，通过logistic函数。

### 步骤5：代入奖励

将我们的 $r$ 表达式代入：

$$P(y_w \succ y_l | x) = \sigma\left( \beta \log \frac{\pi^*(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi^*(y_l|x)}{\pi_{ref}(y_l|x)} \right)$$

**关键观察**：$Z(x)$ 项消掉了！

$$= \sigma\left( \beta \log \frac{\pi^*(y_w|x) / \pi_{ref}(y_w|x)}{\pi^*(y_l|x) / \pi_{ref}(y_l|x)} \right)$$

这就是DPO能工作的原因——难以处理的配分函数消失了。

## DPO损失

因为我们希望策略 $\pi_\theta$ 匹配最优策略 $\pi^*$，我们最大化观察到的偏好的似然：

$$\mathcal{L}_{DPO}(\theta) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma\left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right]$$

使用简化符号和**隐式奖励** $r_\theta(x, y) = \log \frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}$：

$$\mathcal{L}_{DPO}(\theta) = -\mathbb{E} \left[ \log \sigma\left( \beta (r_\theta(x, y_w) - r_\theta(x, y_l)) \right) \right]$$

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         DPO损失直觉                                          │
└─────────────────────────────────────────────────────────────────────────────┘

                          r_w - r_l
              ◄───────────────┼────────────────►
                              │
   模型偏好 y_l               │          模型偏好 y_w
   (错误 - 高损失)            │          (正确 - 低损失)
                              │
         ┌────────────────────┼────────────────────┐
   损失  │                    │                    │
         │    ╲               │               ╱    │
         │     ╲              │              ╱     │
         │      ╲             │             ╱      │
         │       ╲            │            ╱       │
         │        ╲___________│___________╱        │
         └────────────────────┴────────────────────┘
              -∞              0              +∞

    当 r_w - r_l 是大的正数 → 低损失（模型正确排序）
    当 r_w - r_l 是负数 → 高损失（模型错误排序）
```

---

## 理解DPO梯度

取DPO损失的梯度：

$$\nabla_\theta \mathcal{L}_{DPO} = -\beta \mathbb{E} \left[ \underbrace{\sigma(\hat{r}_l - \hat{r}_w)}_{\text{权重}} \left( \underbrace{\nabla_\theta \log \pi_\theta(y_w|x)}_{\text{增加 } y_w} - \underbrace{\nabla_\theta \log \pi_\theta(y_l|x)}_{\text{减少 } y_l} \right) \right]$$

其中：
- $\hat{r}_w = \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}$
- $\hat{r}_l = \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}$

### 梯度解释

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      DPO梯度组成                                             │
└─────────────────────────────────────────────────────────────────────────────┘

梯度有两部分：

1. 权重：σ(r̂_l - r̂_w)
   ┌─────────────────────────────────────────────────────────────────────────┐
   │  • 当模型错误排序时较高（r̂_l > r̂_w）                                    │
   │  • 当模型正确排序时较低（r̂_w > r̂_l）                                    │
   │  → 将学习集中在模型出错的样本上                                          │
   └─────────────────────────────────────────────────────────────────────────┘

2. 方向：∇log π(y_w) - ∇log π(y_l)
   ┌─────────────────────────────────────────────────────────────────────────┐
   │  • 增加偏好回答 y_w 的概率                                               │
   │  • 减少拒绝回答 y_l 的概率                                               │
   │  → 在偏好对上进行对比学习                                                │
   └─────────────────────────────────────────────────────────────────────────┘
```

**关键洞察**：DPO自然地关注模型与人类偏好不一致的难例。

## 隐式奖励

**隐式奖励**是理解DPO的核心：

$$r_\theta(x, y) = \log \frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}$$

**它衡量什么**：回答 $y$ 在训练后策略 $\pi_\theta$ 下比参考策略 $\pi_{ref}$ 下更可能的程度。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      隐式奖励解释                                            │
└─────────────────────────────────────────────────────────────────────────────┘

r_θ(x, y) = log π_θ(y|x) - log π_ref(y|x)

┌─────────────────────────────────────────────────────────────────────────────┐
│  r_θ > 0：训练使 y 更可能（策略偏好这个回答）                               │
│  r_θ = 0：与参考相同的概率（没有变化）                                       │
│  r_θ < 0：训练使 y 更不可能（策略不偏好这个回答）                           │
└─────────────────────────────────────────────────────────────────────────────┘

为什么是"隐式"？
─────────────────────────────────────────────────────────────────────────────
• 我们从不训练单独的奖励模型
• 奖励由策略从参考改变的方式隐式定义
• 在RLHF目标中与显式奖励有相同的数学作用
```

## DPO算法

```
DPO算法：
═══════════════════════════════════════════════════════════════════════════════
输入：参考策略 π_ref，偏好数据集 D = {(x, y_w, y_l)}，β

初始化：π_θ ← π_ref（复制参考策略）

for iteration = 1, 2, ... do:

    ┌─ 采样批次 ──────────────────────────────────────────────────────────────┐
    │  1. 采样偏好对：(x, y_w, y_l) ~ D                                       │
    │     - x：提示                                                            │
    │     - y_w：偏好的（获胜）回答                                            │
    │     - y_l：拒绝的（失败）回答                                            │
    └─────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
    ┌─ 计算对数概率 ──────────────────────────────────────────────────────────┐
    │  2. 通过两个模型进行前向传播：                                           │
    │     log π_θ(y_w|x), log π_θ(y_l|x)    （当前策略）                      │
    │     log π_ref(y_w|x), log π_ref(y_l|x) （参考策略，冻结）               │
    └─────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
    ┌─ 计算隐式奖励 ──────────────────────────────────────────────────────────┐
    │  3. 计算奖励差异：                                                       │
    │     r_w = β(log π_θ(y_w|x) - log π_ref(y_w|x))                          │
    │     r_l = β(log π_θ(y_l|x) - log π_ref(y_l|x))                          │
    └─────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
    ┌─ 计算损失 ──────────────────────────────────────────────────────────────┐
    │  4. DPO损失（二元交叉熵风格）：                                          │
    │     L = -log σ(r_w - r_l)                                               │
    └─────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
    ┌─ 更新 ──────────────────────────────────────────────────────────────────┐
    │  5. 梯度下降：θ ← θ - α∇_θL                                             │
    └─────────────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════════
```

## DPO vs PPO：详细比较

| 方面 | PPO | DPO |
|------|-----|-----|
| **奖励模型** | 需要（单独训练） | 不需要 |
| **训练循环** | RL循环（生成→奖励→更新） | 监督学习 |
| **参考策略** | 用于KL惩罚 | 需要（保存在内存中） |
| **评论家网络** | 需要 | 不需要 |
| **内存** | 策略 + 评论家 + 奖励模型 | 策略 + 参考 |
| **稳定性** | 可能不稳定 | 更稳定 |
| **数据** | 可以在线采样 | 需要离线偏好 |
| **灵活性** | 任何奖励信号 | 仅成对偏好 |

### 何时使用各方法

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         选择你的方法                                         │
└─────────────────────────────────────────────────────────────────────────────┘

使用DPO当：
├── 你有偏好对的静态数据集
├── 你想要更简单的实现和训练
├── 内存有限（不需要奖励模型）
├── 你想要更稳定的训练
└── 成对偏好就足够了

使用PPO当：
├── 你需要在线数据生成
├── 你有非成对奖励信号（如来自代码执行）
├── 你想单独迭代奖励模型
├── 你需要最大的奖励设计灵活性
└── 你有完整RLHF流程的计算资源
```

## 为什么DPO能工作

### 数学等价性

DPO解决与RLHF相同的优化问题：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    RLHF和DPO的等价性                                         │
└─────────────────────────────────────────────────────────────────────────────┘

RLHF目标：
    max_π E[r(x,y)] - β D_KL(π || π_ref)
          ↓
    最优策略：π*(y|x) ∝ π_ref(y|x) exp(r(x,y)/β)
          ↓
    意味着：r(x,y) = β log(π*(y|x)/π_ref(y|x)) + β log Z(x)

DPO方法：
    不显式学习r，使用隐式形式
          ↓
    使用偏好似然优化π_θ来匹配π*
          ↓
    比较两个回答时Z(x)消掉！
          ↓
    结果：相同的最优策略，更简单的路径
```

## 常见陷阱

### 1. 参考策略漂移

**问题**：如果 $\pi_\theta$ 偏离 $\pi_{ref}$ 太远，隐式奖励变得没有意义。

**解决方案**：在训练期间监控 $D_{KL}(\pi_\theta \| \pi_{ref})$；考虑更低的 $\beta$。

### 2. 长度偏差

**问题**：更长的回答自然具有更低的对数概率。

**解决方案**：按序列长度归一化或使用长度控制的训练数据。

### 3. 选中/拒绝不平衡

**问题**：如果 $y_w$ 总是比 $y_l$ 长/短很多，模型学习的是长度而不是质量。

**解决方案**：确保偏好对有相似的长度。

### 4. 遗忘

**问题**：在偏好上的监督训练可能导致灾难性遗忘。

**解决方案**：混入SFT数据，使用回放缓冲区。

## 测验

<details>
<summary><strong>Q1：使DPO成为可能的关键数学洞察是什么？</strong></summary>

**答案**：RLHF目标的最优策略有闭式解：$\pi^*(y|x) \propto \pi_{ref}(y|x) \exp(r(x,y)/\beta)$。重新整理得到 $r(x,y) = \beta \log \frac{\pi^*(y|x)}{\pi_{ref}(y|x)} + \beta \log Z(x)$。当我们在Bradley-Terry模型下计算偏好概率时，配分函数 $Z(x)$ 消掉了，允许我们用策略比率来表示一切。

**关键公式**：$r(x,y) = \beta \log \frac{\pi(y|x)}{\pi_{ref}(y|x)}$

**常见误解**：DPO只是"在偏好上的监督学习"——它实际上是通过不同的路径解决与RLHF相同的约束优化问题。

</details>

<details>
<summary><strong>Q2：写出DPO损失函数并解释每一项。</strong></summary>

**答案**：
$$\mathcal{L}_{DPO} = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log \sigma\left( \beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)} \right) \right]$$

各项：
- $\sigma$：Sigmoid函数，输出偏好概率
- $\beta$：温度参数，控制偏好锐度
- $\log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}$：偏好回答的隐式奖励
- $\log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}$：拒绝回答的隐式奖励
- 差值给出当前策略下的相对偏好

</details>

<details>
<summary><strong>Q3：为什么DPO需要在内存中保留参考策略？</strong></summary>

**答案**：参考策略有两个关键作用：

1. **定义隐式奖励**：$r_\theta(x,y) = \log \frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)}$ 需要计算 $\pi_{ref}$ 下的对数概率

2. **提供正则化**：没有参考，模型可以分配任意概率。与参考的比率隐式地惩罚偏离。

这是一个关键权衡：DPO消除了奖励模型但需要在内存中保留 $\pi_{ref}$（策略内存翻倍）。

**常见误解**：有些人认为DPO是"纯监督学习"——但与 $\pi_{ref}$ 的参考策略连接才是使其在数学上等价于KL正则化RLHF的关键。

</details>

<details>
<summary><strong>Q4：梯度权重 $\sigma(\hat{r}_l - \hat{r}_w)$ 告诉我们关于DPO学习动态的什么？</strong></summary>

**答案**：权重 $\sigma(\hat{r}_l - \hat{r}_w)$ 在模型错误排序对时较高（给 $y_l$ 分配比 $y_w$ 更高的隐式奖励），正确排序时较低。

**解释**：
- 当 $\hat{r}_w > \hat{r}_l$（正确）：$\sigma(\hat{r}_l - \hat{r}_w) \approx 0$ → 小梯度
- 当 $\hat{r}_l > \hat{r}_w$（错误）：$\sigma(\hat{r}_l - \hat{r}_w) \approx 1$ → 大梯度

这是**自适应加权**——DPO自动将学习集中在模型与人类偏好不一致的样本上，类似于难负例挖掘。

**陷阱**：如果模型在某些对上变得过于自信，它可能完全停止从它们学习。

</details>

<details>
<summary><strong>Q5：你正在进行DPO训练，注意到损失在下降但模型质量在变差。可能是什么问题，如何修复？</strong></summary>

**答案**：这通常表明以下问题之一：

1. **检查长度博弈**：模型是否在学习偏好更长/更短的回答而不管质量？比较选中vs拒绝的长度分布。

2. **监控KL散度**：如果 $D_{KL}(\pi_\theta \| \pi_{ref})$ 很大，模型可能在偏好数据上过拟合。尝试更低的 $\beta$。

3. **检查隐式奖励**：绘制 $r_\theta(y_w) - r_\theta(y_l)$ 分布。如果它饱和（所有值都是很大的正数），梯度消失。

4. **检查数据质量**：偏好标签可能有噪声或矛盾。

5. **在留出数据上评估**：训练损失可以下降而测试性能下降（过拟合）。

**调试策略**：从 β=0.1 开始，监控KL，使用长度归一化，维护带有人类评估的验证集。

</details>
