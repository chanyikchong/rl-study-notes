# 强化学习学习笔记

欢迎使用**强化学习学习笔记** — 一份全面、面试就绪的RL概念、数学和实践实现资源。

## 内容概览

- **严谨的数学基础**: 关键方程的清晰推导与直观解释
- **面试导向内容**: 每个主题突出需要记忆的要点和常见面试问题
- **实用代码示例**: 主要算法的可运行实现
- **互动测验**: 通过点击显示的问答测试你的理解

## 按章节的主题

### 1. 基础知识（从这里开始！）

| 主题 | 学习内容 | 关键概念 |
|------|----------|----------|
| [MDP基础](fundamentals/mdp.md) | RL的数学框架 | 状态、动作、奖励、转移、回报 |
| [策略与价值函数](fundamentals/policy-value.md) | 如何评估和比较行为 | $\pi(a|s)$, $V^\pi(s)$, $Q^\pi(s,a)$ |
| [贝尔曼方程](fundamentals/bellman.md) | 价值的递归结构 | 贝尔曼期望方程、贝尔曼最优方程 |
| [计算价值函数](fundamentals/computing-values.md) | **RL如何实际计算 V, Q, A** | DP vs MC vs TD、优势函数 |
| [同策略与异策略](fundamentals/on-off-policy.md) | 两种学习范式 | 行为策略、目标策略、重要性采样 |

### 2. 动态规划（有模型方法）

当你有转移模型 $P(s'|s,a)$ 时：

| 主题 | 学习内容 | 关键概念 |
|------|----------|----------|
| [策略评估](dp/policy-evaluation.md) | 为固定策略计算 $V^\pi$ | 迭代更新、收敛性 |
| [策略迭代](dp/policy-iteration.md) | 通过交替找到最优策略 | 评估 → 改进 → 重复 |
| [值迭代](dp/value-iteration.md) | 直接计算 $V^*$ | 贝尔曼最优备份 |

### 3. 无模型表格方法

当你只有经验（没有模型）时：

| 主题 | 学习内容 | 关键概念 |
|------|----------|----------|
| [蒙特卡洛方法](mc/monte-carlo.md) | 从完整轨迹学习 | 首次访问MC、探索性开始 |
| [SARSA](td/sarsa.md) | 同策略TD控制 | $Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma Q(s',a') - Q(s,a)]$ |
| [Q学习](td/q-learning.md) | 异策略TD控制 | $Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma \max_{a'} Q(s',a') - Q(s,a)]$ |
| [期望SARSA](td/expected-sarsa.md) | 方差减少 | 使用下一步动作的期望值 |

### 4. 函数逼近

超越表格方法（大型/连续状态空间）：

| 主题 | 学习内容 | 关键概念 |
|------|----------|----------|
| [线性方法](fa/linear.md) | 基于特征的逼近 | $\hat{V}(s) = \mathbf{w}^\top \phi(s)$ |
| [神经网络](fa/neural.md) | 深度函数逼近 | 非线性特征、训练挑战 |

### 5. 深度强化学习

现代RL算法：

| 主题 | 学习内容 | 方法 |
|------|----------|------|
| [DQN](deep/dqn.md) | 深度Q网络 | **基于价值**, 异策略, 离散动作 |
| [策略梯度](deep/policy-gradients.md) | REINFORCE算法 | **基于策略**, 同策略, 高方差 |
| [Actor-Critic](deep/actor-critic.md) | A2C, A3C架构 | **混合方法**: 策略(actor) + 价值(critic) |
| [PPO](deep/ppo.md) | 近端策略优化 | **许多任务的最先进方法** |

**深度RL的演进：**
```
REINFORCE (高方差)
    → Actor-Critic (用基线减少方差)
        → A2C/A3C (优势 + 并行)
            → PPO (通过截断稳定更新)
```

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 本地启动文档
mkdocs serve

# 运行算法示例
python -m rl_examples.run --algo q_learning
python -m rl_examples.run --algo dqn
python -m rl_examples.run --algo ppo
```
