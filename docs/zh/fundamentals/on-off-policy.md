# 同策略与异策略学习

## 面试摘要

**同策略（On-policy）**方法学习用于生成数据的策略（行为策略 = 目标策略）。**异策略（Off-policy）**方法学习与生成数据不同的策略（行为策略 ≠ 目标策略）。SARSA是同策略的（学习ε-贪婪的价值），Q学习是异策略的（在探索时学习最优策略）。异策略支持经验回放和从演示中学习，但需要重要性采样修正以保证收敛。

**需要记忆的**：行为策略/目标策略的定义，SARSA vs Q学习的区别，为什么异策略能使用回放缓冲区，异策略MC的重要性采样。

---

## 设计动机：为什么有两种类型？

### 探索-利用困境

为了学习好，智能体必须：
1. **探索**：尝试新动作以发现其效果
2. **利用**：使用当前知识最大化奖励

**问题**：如果总是利用（贪婪），永远不会发现更好的动作。如果总是探索（随机），永远不会使用所学的知识。

**常见解决方案**：使用ε-贪婪——大多数时候贪婪，有时随机。

### 但我们应该学习什么？

这就是同策略与异策略的区别：

**同策略思维**："我正在用ε-贪婪行为，所以我应该学习ε-贪婪行为的价值。"

**异策略思维**："我正在用ε-贪婪进行探索，但我想学习贪婪（最优）策略的价值。"

```
同策略：学习 V^π 其中 π = 行为策略（ε-贪婪）
异策略：学习 V^π* 其中 π* = 最优策略（贪婪）
        同时按照 π_b（ε-贪婪）行为
```

## 核心定义

### 行为策略 vs 目标策略

| 术语 | 符号 | 定义 |
|------|--------|------------|
| **行为策略** | $\pi_b$ 或 $b$ | 用于生成经验（选择动作）的策略 |
| **目标策略** | $\pi$ | 我们想要评估或改进的策略 |

### 同策略

$$\pi_b = \pi$$

- 我们学习正在使用的同一策略
- 数据来自我们正在评估的策略
- 更简单，更稳定

**示例**：SARSA, REINFORCE, A2C, PPO

### 异策略

$$\pi_b \neq \pi$$

- 我们学习与正在使用的不同策略
- 可以在探索时学习最优策略
- 可以重用旧数据（经验回放）
- 样本效率更高，但更复杂

**示例**：Q学习, DQN, SAC, 异策略actor-critic

## 为什么这个区别重要？

### 例子：悬崖行走问题

```
[S][ ][ ][ ][ ][ ][ ][ ][ ][ ][ ][G]
[C][C][C][C][C][C][C][C][C][C][C][C]

S = 起点, G = 目标, C = 悬崖（奖励 = -100，重置到S）
正常步骤奖励 = -1
```

**ε-贪婪，ε = 0.1**：

**SARSA（同策略）**：
- 学习ε-贪婪策略的价值
- 知道由于ε有时会掉下悬崖
- 学习走安全路径（远离悬崖边缘）
- 实际行为与学习的策略匹配

**Q学习（异策略）**：
- 学习最优（贪婪）策略的价值
- 最优策略沿着悬崖边缘走（最短路径）
- 但智能体是ε-贪婪的，所以有时会掉下去！
- 学习的Q值不考虑探索的随机性

```
SARSA路径：   S → → → → → → → → → → → G  （安全，较长）
               ↑ 避开悬崖边缘

Q学习路径：   S → → → → → → → → → → → G  （最优但有风险）
              沿悬崖走，10%的时间掉下去
```

**关键洞见**：同策略更"安全"因为它学习实际行为。异策略更"乐观"——它学习最佳可能的策略。

## 数学：为什么异策略需要修正

### 同策略：不需要修正

当 $\pi_b = \pi$ 时，期望很直接：

$$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$$

我们从 $\pi$ 采样轨迹，计算回报，取平均。完成。

### 异策略：分布不匹配

当 $\pi_b \neq \pi$ 时，我们有一个问题：

$$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$$

但我们的数据来自 $\pi_b$，不是 $\pi$！状态-动作分布是错误的。

### 重要性采样

**解决方案**：重新加权样本以修正分布不匹配。

$$V^\pi(s) = \mathbb{E}_{\pi_b}\left[ \rho_t G_t | S_t = s \right]$$

其中**重要性采样比率**是：

$$\rho_t = \prod_{k=t}^{T-1} \frac{\pi(A_k|S_k)}{\pi_b(A_k|S_k)}$$

**直觉**：如果目标策略 $\pi$ 比行为策略 $\pi_b$ 更频繁地采取动作 $a$，我们就增加该样本的权重。

### 问题：高方差

比率的乘积可能爆炸：

$$\rho_t = \frac{\pi(a_t)}{\pi_b(a_t)} \times \frac{\pi(a_{t+1})}{\pi_b(a_{t+1})} \times ... \times \frac{\pi(a_{T-1})}{\pi_b(a_{T-1})}$$

如果任何 $\pi_b(a) \approx 0$ 而 $\pi(a) > 0$，比率会变得巨大！

**解决方案**：
- 加权重要性采样（更低方差，有些偏差）
- 每决策重要性采样（只修正一步）
- 使用TD方法（自然处理单步更新）

---

## 为什么Q学习不需要重要性采样

这是Q学习的魔力：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

$\max_{a'}$ 操作符隐式选择贪婪动作。我们不需要知道在 $\pi_b$ 下采取该动作的概率。

**关键洞见**：Q学习"免费"获得异策略能力因为：
1. 我们观察 $(s, a, r, s')$——哪个策略选择了 $a$ 无关紧要
2. 目标 $r + \gamma \max_{a'} Q(s', a')$ 是针对贪婪策略的
3. 我们只需要单步更新，不需要完整轨迹修正

**但是**：这只适用于单步TD。多步异策略Q学习确实需要修正。

## 方法比较

### 同策略方法

| 方法 | 类型 | 关键特征 |
|--------|------|-------------|
| **SARSA** | TD | 向 r + γQ(s',a') 更新 Q(s,a)，其中 a' 来自行为策略 |
| **Expected SARSA** | TD | 向行为策略下的期望值更新 |
| **REINFORCE** | 策略梯度 | 使用行为策略的回报 |
| **A2C/A3C** | Actor-Critic | Critic评估行为策略 |
| **PPO** | 策略梯度 | 限制每次更新的策略变化 |

### 异策略方法

| 方法 | 类型 | 关键特征 |
|--------|------|-------------|
| **Q学习** | TD | 使用 max_a' Q(s',a')——贪婪目标 |
| **DQN** | 深度TD | Q学习 + 神经网络 + 回放缓冲区 |
| **DDPG** | Actor-Critic | 带确定性策略的异策略 |
| **SAC** | Actor-Critic | 最大熵异策略 |
| **TD3** | Actor-Critic | 改进的DDPG |

## SARSA vs Q学习：并排比较

### 更新规则

**SARSA**（状态-动作-奖励-状态-动作）：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma Q(s', a') - Q(s, a) \right]$$

其中 $a'$ 是行为策略**实际采取的下一个动作**。

**Q学习**：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

其中 $\max_{a'}$ 选择**最佳动作**，不管实际采取了什么。

### 算法比较

```
SARSA：
1. 在状态 s，用 Q 的 ε-贪婪选择 a
2. 采取动作 a，观察 r, s'
3. 用 Q 的 ε-贪婪选择 a'        ← 使用实际下一个动作
4. Q(s,a) ← Q(s,a) + α[r + γQ(s',a') - Q(s,a)]
5. s ← s', a ← a'

Q学习：
1. 在状态 s，用 Q 的 ε-贪婪选择 a
2. 采取动作 a，观察 r, s'
3. Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)]  ← 使用max
4. s ← s'
```

### 数值例子

```
状态 s，两个动作：LEFT, RIGHT
当前：Q(s, LEFT) = 10, Q(s, RIGHT) = 5
智能体采取 LEFT（ε-贪婪选择了贪婪）
奖励 r = 2，到达 s' 其中 Q(s', LEFT) = 8, Q(s', RIGHT) = 12
下一个动作 a' = RIGHT（ε-贪婪选择了贪婪）
α = 0.1, γ = 0.9

SARSA更新：
  目标 = r + γ Q(s', a') = 2 + 0.9 × 12 = 12.8
  Q(s, LEFT) ← 10 + 0.1 × (12.8 - 10) = 10.28

Q学习更新：
  目标 = r + γ max_a' Q(s', a') = 2 + 0.9 × max(8, 12) = 12.8
  Q(s, LEFT) ← 10 + 0.1 × (12.8 - 10) = 10.28

这里结果相同！但如果 a' 是随机的（ε探索）：

如果 ε 导致 a' = LEFT（随机）：
  SARSA：目标 = 2 + 0.9 × 8 = 9.2
         Q(s, LEFT) ← 10 + 0.1 × (9.2 - 10) = 9.92

  Q学习：目标 = 2 + 0.9 × 12 = 12.8（仍然使用max！）
         Q(s, LEFT) ← 10 + 0.1 × (12.8 - 10) = 10.28

现在它们不同了！Q学习忽略次优的探索性动作。
```

## 为什么异策略能实现经验回放

### 回放缓冲区

异策略方法可以存储过去的转移并重新学习：

```
回放缓冲区：[(s₁,a₁,r₁,s₁'), (s₂,a₂,r₂,s₂'), ..., (sₙ,aₙ,rₙ,sₙ')]
```

**为什么Q学习可以这样做**：
- Q学习的更新不依赖于哪个策略选择了动作
- 旧的转移仍然是有效的训练数据
- 可以均匀采样以获得更好的学习

**为什么SARSA不能这样做**：
- SARSA使用 $Q(s', a')$ 其中 $a'$ 是实际的下一个动作
- 旧数据是由旧策略 $\pi_{old}$ 生成的
- 当前策略 $\pi_{new}$ 会选择不同的 $a'$
- 使用旧的 $a'$ 会给出错误的更新！

### 样本效率

```
同策略：使用一次数据，丢弃
异策略：存储数据，多次重用

数据效率：异策略 >> 同策略
```

这就是为什么DQN（异策略）比REINFORCE（同策略）样本效率高得多。

## 常见陷阱

1. **认为"异策略=不好"**：异策略支持回放缓冲区和从演示中学习。它通常样本效率更高。

2. **忘记SARSA需要a'**：SARSA需要在更新前观察下一个动作。Q学习不需要。

3. **对同策略方法使用回放缓冲区**：这破坏了收敛保证！同策略方法需要当前策略的新鲜数据。

4. **忽略悬崖行走的教训**：当探索是危险的时候，同策略学习更安全的策略。异策略学习最优但可能不考虑探索风险。

5. **认为总是需要重要性采样**：Q学习的单步TD避免了它。多步方法需要修正。

6. **混淆"探索"和"异策略"**：ε-贪婪是探索策略。你是同策略还是异策略取决于你学习的是什么，而不是你如何探索。

## 小例子：各自何时最佳

### 同策略优先：机器人学习

机器人学习行走应该使用同策略因为：
- 安全很重要——学习实际行为
- 摔倒代价高——SARSA学习避免有风险的状态
- 策略逐渐变化——没有突然的危险行为

### 异策略优先：游戏

Atari游戏智能体应该使用异策略因为：
- 可以多次回放有趣的经验
- 从人类演示学习是异策略的
- 样本效率很重要——不能玩数百万局游戏
- 没有现实世界的安全问题

## 测验

<details markdown="1">
<summary><strong>问题1（概念）：</strong> 同策略和异策略学习的关键区别是什么？</summary>

**答案**：同策略学习生成数据的同一策略（行为=目标）。异策略学习与生成数据不同的策略（行为≠目标）。

**解释**：
- 同策略：$\pi_b = \pi$——评估/改进你正在使用的策略
- 异策略：$\pi_b \neq \pi$——使用不同的行为策略评估/改进目标策略

**关键方程**：
- SARSA（同策略）：向 $Q(s', a')$ 更新，其中 $a'$ 来自行为策略
- Q学习（异策略）：向 $\max_{a'} Q(s', a')$ 更新——最优策略

**常见陷阱**：认为探索使某物成为异策略。带ε-贪婪的SARSA仍然是同策略的！
</details>

<details markdown="1">
<summary><strong>问题2（概念）：</strong> 为什么Q学习可以使用经验回放而SARSA不能？</summary>

**答案**：Q学习的更新（$\max_{a'}$）独立于哪个策略生成了数据。SARSA的更新使用实际的下一个动作 $a'$，这依赖于行为策略。

**解释**：
- Q学习：$r + \gamma \max_{a'} Q(s', a')$——无论 $(s,a,r,s')$ 如何收集，目标都相同
- SARSA：$r + \gamma Q(s', a')$——需要知道当前策略会采取什么动作

旧策略 $\pi_{old}$ 的数据有 $\pi_{old}$ 选择的 $a'$。用当前 $\pi_{new}$ 的SARSA使用这个会产生有偏的更新。

**常见陷阱**：尝试对同策略方法使用回放缓冲区。这破坏了同策略假设。
</details>

<details markdown="1">
<summary><strong>问题3（数学）：</strong> 什么是重要性采样，什么时候需要它？</summary>

**答案**：重要性采样重新加权行为策略 $\pi_b$ 的样本以估计目标策略 $\pi$ 下的期望：

$$\mathbb{E}_\pi[f(x)] = \mathbb{E}_{\pi_b}\left[ \frac{\pi(x)}{\pi_b(x)} f(x) \right]$$

**何时需要**：
- 异策略蒙特卡洛方法（完整轨迹修正）
- 异策略多步TD方法
- 使用旧数据的策略梯度方法

**何时不需要**：
- 单步Q学习（max操作符处理了）
- 带函数逼近的单步异策略TD（半梯度方法）

**关键方程**：$\rho_t = \prod_{k=t}^{T-1} \frac{\pi(A_k|S_k)}{\pi_b(A_k|S_k)}$

**常见陷阱**：当策略差异很大时，重要性比率可能有非常高的方差。
</details>

<details markdown="1">
<summary><strong>问题4（概念）：</strong> 在悬崖行走例子中，为什么SARSA找到与Q学习不同的路径？</summary>

**答案**：SARSA学习ε-贪婪策略的价值（考虑随机探索），而Q学习学习最优策略（假设贪婪执行）。

**解释**：
- Q学习：价值反映沿悬崖边缘的最优路径
- 但智能体是ε-贪婪的，所以有时会掉下去
- SARSA：价值考虑10%随机动作的概率
- 学习到悬崖边缘状态在ε-贪婪下是有风险的
- 走更长但更安全的路径

**关键洞见**：同策略方法对实际行为"现实"。异策略方法对最优执行"乐观"。

**常见陷阱**：假设异策略总是给出更好的策略。在安全关键应用中，同策略可能更好。
</details>

<details markdown="1">
<summary><strong>问题5（实践）：</strong> 你的DQN智能体学习很慢。你从均匀回放采样切换到同策略（只使用最新经验）。会发生什么？</summary>

**答案**：由于相关样本和失去多样经验，性能可能会下降。

**解释**：
1. **相关样本**：连续经验高度相关，导致梯度不稳定
2. **灾难性遗忘**：没有回放，智能体忘记如何处理旧状态
3. **失去多样性**：缺少罕见但重要的转移
4. **破坏DQN设计**：DQN假设从回放缓冲区采样i.i.d.样本

这就是为什么回放缓冲区对DQN的稳定性至关重要。

**常见陷阱**：认为"新鲜数据更好"。对于异策略方法，多样的旧数据通常比相关的新数据更有价值。
</details>

<details markdown="1">
<summary><strong>问题6（概念）：</strong> PPO是同策略还是异策略？为什么？</summary>

**答案**：PPO是同策略的，但它通过裁剪重要性比率在"信任区域"内重用数据。

**解释**：
- PPO用当前策略 $\pi_\theta$ 收集数据
- 更新策略同时限制变化幅度
- 裁剪机制限制 $\frac{\pi_\theta(a|s)}{\pi_{\theta_{old}}(a|s)}$ 在 $[1-\epsilon, 1+\epsilon]$
- 更新后，旧数据被丢弃（不能跨epoch重用）

**为什么不是真正的异策略**：
- 数据只来自最近的策略版本
- 重要性比率被限制以保持"接近"同策略
- 不能像Q学习那样使用任意旧数据

**常见陷阱**：认为PPO的多个epoch使它成为异策略。它是有控制重用的同策略。
</details>

## 算法概述

### 同策略TD（SARSA）

```
任意初始化 Q(s,a)
对每个回合：
    s = 初始状态
    a = ε-greedy(Q, s)          # 选择第一个动作

    当未终止时：
        采取动作 a，观察 r, s'
        a' = ε-greedy(Q, s')    # 现在选择下一个动作
        Q(s,a) += α[r + γQ(s',a') - Q(s,a)]
        s, a = s', a'           # 向前传递
```

### 异策略TD（Q学习）

```
任意初始化 Q(s,a)
对每个回合：
    s = 初始状态

    当未终止时：
        a = ε-greedy(Q, s)
        采取动作 a，观察 r, s'
        Q(s,a) += α[r + γ max_a' Q(s',a') - Q(s,a)]  # max，不是实际的
        s = s'
```
